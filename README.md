# CodeChef Practice — Basic Problems (0–500 Difficulty)
 
This repository contains my solutions to the most basic problems available on [CodeChef](https://www.codechef.com/), in the difficulty range of **0 – 500**.
 
## 🎯 Purpose
 
- Build a strong foundation in problem-solving.
- Get comfortable with reading input/output in JavaScript for competitive programming.
- Track progress as I move from beginner to intermediate problems.
## 🛠️ Language Used
 
- **JavaScript** (Node.js)
## 📂 Repository Structure
 
Each problem has its own folder (or markdown file) containing:
- The problem statement
- Input/Output format
- Constraints
- Sample test cases with explanations
- My solution code
- A brief explanation of my approach
```
.
├── README.md
├── problem-1-cricket-world-cup-qualifier/
│   └── cricket-world-cup-qualifier.md
├── problem-2-.../
│   └── ...
└── ...
```

## 🚀 How to Run
 
Each solution reads input from `stdin` using Node's built-in `readline` module. To run a solution locally:
 
```bash
node solution.js
```
 
Then type/paste the input and press Enter.
